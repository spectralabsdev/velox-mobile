# Velox Mobile

Public support, privacy and feedback repository for Velox Mobile, an independent
Salesforce administration and developer tool for iOS and Android.

App Store and Google Play listings are not published yet. Store links will be
added when available. Application source code is maintained privately and is
not included in this repository.

## Public pages

Public pages:

- https://spectralabsdev.github.io/velox-mobile/
- https://spectralabsdev.github.io/velox-mobile/purchase/
- https://spectralabsdev.github.io/velox-mobile/privacy/
- https://spectralabsdev.github.io/velox-mobile/support/
- https://spectralabsdev.github.io/velox-mobile/data-deletion/

Publisher: Giohanna Hervias. Contact: spectralabsdev@gmail.com.

For a bug report, include the app version, operating system, device model and
steps to reproduce. Public issues must not include passwords, tokens, customer
records or confidential code. Send security and privacy requests by email.

## Website setup

Publish `docs/` from `main` through GitHub Pages and enable Issues. Use the issue
forms in `.github/ISSUE_TEMPLATE/`. Configure and verify the custom domain before
pointing DNS to Pages, then enable HTTPS. Update store and app URLs only after
the new pages have been verified publicly.
